# Smart Nature

האתר הציבורי: https://smartnature-7fr5l6n5la-uc.a.run.app

כניסה ללא התחברות או אישור אישי. לשיתוף עם בוחנים יש להשתמש בכתובת הבסיס לעיל, ללא הפרמטר visit.

אבטיפוס ציבורי לתכנון טיול, דיווח מהשטח וניתוח AI. ממשק Streamlit בעברית, נתוני הדגמה היסטוריים, BigQuery לשיחות ודיווחים מבודדים, אחסון תמונות פרטי ו־Google Gen AI.

## מצב הנתונים

נתוני המקור הועתקו ואומתו לפרויקט `yotamsofer-513010`, בדאטהסט `smart_nature_DB`: שלושה משתמשים, 50 אתרים, שלושה דיווחים ו־16 הודעות. האפליקציה החדשה אינה מציגה למבקרים משתמשים או שיחות היסטוריות ואינה משנה את נתוני המקור. מפת הדמו משתמשת בעותק CSV שנוצר מהמקור, עם מועד העדכון המקורי והבהרה שאינו מידע בזמן אמת. שמות ותיאורים בעברית הם תוויות תצוגה, לא אימות גאוגרפי נוסף.

`smart_nature_demo` מכיל הודעות, דיווחים, מוני שימוש ומונה תקציב משותף. לכל ביקור מזהה המופק מגיבוב אסימון אקראי בקישור. האסימון עצמו אינו נשמר במסד. שיתוף הקישור האישי נותן גישה לשיחה של אותו ביקור; לשיתוף המוצר יש להסיר את הפרמטר `visit`. זהו מנגנון אורח ולא מערכת חשבונות מאומתים.

דיווח חדש ממתין לבדיקה. המבקר יכול לדמות אישור בביקור שלו בלבד. ההדמיה יכולה להחמיר סטטוס אך לא לפתוח מחדש אתר סגור. אין מוקד אנושי שמקבל את דיווחי הדמו ואין קביעה רשמית של מצב שטח.

## הפעלה מקומית

נדרש Python 3.12. גרסאות כל התלויות נעולות ב־requirements.txt; requirements.in הוא קובץ המקור לעדכון גרסאות.

```sh
uv venv --python 3.12 .venv
uv pip sync --python .venv/bin/python requirements.txt
.venv/bin/python -m streamlit run app.py
```

ההגדרות הלא סודיות מופיעות ב־`.streamlit/secrets.example.toml`. מקומית אפשר להשתמש בחשבון השירות הקיים שב־secrets.toml או ב־Application Default Credentials. אין להעתיק מפתחות ל־Git, לתמונת Docker או לחומרי ההצגה.

לעיון במפה ובממשק ללא גישה לענן:

```sh
SMARTNATURE_OFFLINE=1 .venv/bin/python -m streamlit run app.py
```

במצב זה השליחה וה־AI מושבתים; אין הצגת הצלחה מדומה לשמירה שלא התבצעה.

## בדיקות

```sh
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python infra/audit_restoration.py
.venv/bin/python infra/acceptance_check.py
```

בדיקות היחידה והממשק אינן דורשות ענן. audit_restoration קורא את המקור והיעד ומשווה כל רשומה וסכמה. acceptance_check יוצר נתוני בדיקה מבודדים בדמו, בודק תמונה פרטית, בידוד, חזרה לשיחה ומכסת שימוש, ומבצע שתי קריאות AI. נתוני הבדיקה נמחקים במחזור התפוגה של הדמו.

## הגנות והתנהגות בכשל

- עד 2,000 תווים לבקשה ותמונה עד 5MB ועד 20 מגה־פיקסל. התמונה מאומתת, מוקטנת ומקודדת מחדש ללא EXIF/GPS.
- עד 20 פעולות לביקור ביום ו־300 פעולות לכל הדמו ביום; בין פעולות נדרשות חמש שניות לפחות. המונה המשותף מתעדכן בעסקה. כשל במסד או התנגשות בעסקה מונעים קריאת מודל; הבקשה אינה נעקפת דרך זיכרון מקומי.
- תשובות מודל נבדקות גם בקוד. סטטוס שגוי או כשל בניתוח הופכים ל־Unknown; אתר שאינו עובר סינון רכב/סטטוס לא נכנס לרשימת ההמלצות.
- הוראות ניתוח מפגעים נפרדות מהוראות המלצה. הדוגמאות הישנות ב־knowledge_base.py נשמרות לצורכי מקור בלבד ואינן מוזנות למודל.
- מזג אוויר נשלף לאתר נבחר בלבד, עם timeout ומטמון של 15 דקות. כשל בו אינו משבית את המפה.
- מידע הדמו נשמר בטבלאות מחולקות לפי זמן עם תפוגת מחיצות של שבעה ימים, ונקרא רק בחלון שבעת הימים האחרונים. המחיקה הפיזית של הספק אינה מיידית; BigQuery עשוי להחזיק היסטוריית שחזור פנימית. מחיקת תמונות לפי lifecycle של שבעה ימים מתבצעת אסינכרונית.

## הרשאות ופריסה

חשבון `smartnature-runtime` בפרויקט החדש משתמש בזהות מובנית ב־Cloud Run, ללא מפתח. גישת הנתונים ההיסטוריים שלו היא לקריאה בלבד; כתיבה מותרת בסביבת הדמו. גישה לתמונות ניתנת בדלי הפרטי בלבד, עם חסימת גישה ציבורית. תמונה מוצגת רק אחרי בדיקת שיוך לביקור בצד השרת.

Dockerfile משתמש ברשימת קבצים מפורשת. `.dockerignore` ו־`.gcloudignore` מונעים הכללת מפתחות, גיבויים, מסדי נתונים מקומיים וסביבות Python. Cloud Build מריץ את הבדיקות ב־Linux ובודק את נתיב הבריאות של התמונה. סקריפט build_release אינו מפרסם אתר.

הגדרות האירוח והעלות אושרו והפריסה הציבורית בוצעה. לבנייה או לפריסה חוזרת:

```sh
.venv/bin/python infra/build_release.py
.venv/bin/python infra/deploy_release.py
.venv/bin/python infra/deploy_release.py --apply
.venv/bin/python infra/setup_operations.py --url https://DEPLOYED-HOST --apply
```

תצורת הפריסה: `us-central1`, מעבד אחד, זיכרון 1GiB, מופע חם אחד ומקסימום מופע אחד, עד 15 חיבורים במקביל, timeout של שעה ו־session affinity. הכתובת ציבורית; מסד הנתונים ודלי התמונות פרטיים. affinity אינה מבטיחה שמירת תהליך, ולכן שיחות ודיווחים נשמרים במסד. נבדקה חזרה לשיחה מהמסד לאחר העלאת revision חדש וחיבור מחדש לביקור.

setup_operations מיועד להגדיר בדיקת בריאות חיצונית כל חמש דקות, התרעת אי־זמינות לבעל החשבון המחובר, תקציב התראות של 160 ₪ לחודש (בקירוב $50 לפי השער שנבדק בעת ההקמה) וגיבוי יומי של הנתונים ההיסטוריים באמצעות snapshots ל־30 יום. הניטור, ההתראות והתזמון הופעלו לאחר הפריסה; תוצאות האימות מתועדות ב־infra/operations_result.json. התראת תקציב אינה תקרת הוצאה. snapshots אינם כוללים נתוני אורחים כדי לא להאריך את שמירתם מעבר למדיניות הדמו.

## גיבוי ושחזור

הגיבוי הפרטי לפני השינויים נמצא ב־backups/20261108T102732Z, מוחרג מ־Git. הוא כולל סכמות, נתונים, חתימות קבצים וקוד ללא סודות. בוצע תרגול שחזור לענן בדאטהסט בדיקה חדש; ארבע הטבלאות שוחזרו ונבדקו. טבלאות התרגול פגות לאחר יום.

```sh
.venv/bin/python infra/restore_backup.py backups/20261108T102732Z
.venv/bin/python infra/restore_backup.py backups/20261108T102732Z --dataset NEW_DATASET --apply
```

השחזור מסרב לעבוד על דאטהסט שכבר קיים ומשתמש ב־WRITE_EMPTY. ברירת המחדל לטבלאות שחזור היא תפוגה של יום; יש להאריך במפורש אם נדרש שחזור קבוע. לחזרה לגרסת אפליקציה קודמת, יש לבחור revision קודם מתוך Cloud Run ולהעביר אליו תעבורה; אין להחזיר לאחור נתוני מקור או מפתחות.
